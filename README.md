COMPUTER VISION MODEL FOR AN AI BUDDY PROJECT 
The model contains object detection using YOLO, face recognition, and hand tracking 

How to run 

Create a venv in dir contaning program files 

```
python -m venv venv 
```
Now Activate venv
```
source path/venv/bin/activate
```
Install requirements - packages needed to run the program 

```
pip install -r requirements.txt
```
Now run main_camera_runner.py

```
python main_camera_runner.py
```
